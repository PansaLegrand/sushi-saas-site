## Prérequis

- Node.js `>=20.19.0 <23`
- pnpm `10.22.0`
- Docker Compose pour PostgreSQL et Redis par défaut

## Lancement local

```bash
git clone https://github.com/PansaLegrand/sushi-saas-template.git
cd sushi-saas-template
pnpm install
pnpm setup
pnpm dev
```

`pnpm setup` est idempotent : il ne crée `.env` que s’il est absent, démarre PostgreSQL et Redis, crée des bases de développement et de test isolées, puis applique les migrations versionnées. Il n’écrase jamais un `.env` existant.

Ouvrez `http://localhost:3000`. Lancez `pnpm dev:admin` pour l’application d’administration indépendante sur `http://localhost:3001`.

## Vérification

```bash
curl http://localhost:3000/api/health
curl http://localhost:3000/api/ready
pnpm lint
pnpm test:run
pnpm build
```

`/api/health` teste la vivacité ; `/api/ready` vérifie configuration, base et migrations, Redis et file de jobs.

## Carte de configuration

Le `.env` généré contient des valeurs locales sûres. En production, configurez les URL, `BETTER_AUTH_SECRET`, PostgreSQL, Redis et une source d’IP fiable, `CRON_SECRET` et Turnstile. Stripe, Resend, Slack et le stockage S3 ne sont requis que pour les fonctions activées.

Anglais, chinois, espagnol, français et japonais sont inclus ; contrôlez-les avec `NEXT_PUBLIC_LOCALES`. Les guides publics vivent dans ce dépôt séparé, relié par `NEXT_PUBLIC_DOCS_URL`.
