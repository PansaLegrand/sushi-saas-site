> Verificado con el commit [`b16b416`](https://github.com/PansaLegrand/sushi-saas-template/tree/b16b416d3ac2f50d2e6f2c25ce5736b91f6740b9).

Al terminar tendrás la app cliente, consola admin, Content Studio, worker durable, bases SaaS de desarrollo/test, base Payload, Redis y un bucket S3 privado local funcionando juntos.

## Requisitos

- Node.js `>=20.19.0 <23`
- pnpm `10.22.0`
- Docker Compose

## Primera ejecución guiada

```bash
git clone https://github.com/PansaLegrand/sushi-saas-template.git
cd sushi-saas-template
pnpm install
./scripts/setup.sh development
pnpm dev:doctor
pnpm dev:all
```

El setup abre `pnpm customize`, crea perfiles ignorados que falten, inicia PostgreSQL, Redis y Garage, crea `sushi_dev`, `sushi_test`, `sushi_content` y la base de restore, aplica migraciones Drizzle/Payload y prepara el bucket `sushi-dev`. Es idempotente y nunca sobrescribe un archivo existente. Usa `pnpm setup` si quieres conservar los valores neutros.

`dev:doctor` comprueba en modo lectura versiones, límites y permisos de entorno, Docker, bases, Redis, migraciones, objetos, Studio y puertos sin imprimir secretos.

`dev:all` inicia:

| Proceso | Dirección |
| --- | --- |
| App cliente | `http://localhost:3000` |
| Admin | `http://localhost:3001` |
| Content Studio | `http://localhost:3002/admin` |
| Worker | proceso de fondo con logs prefijados |

## Fixtures y reset seguros

```bash
pnpm dev:seed
pnpm dev:reset -- --dry-run
pnpm dev:reset
```

Seed crea o repara de forma idempotente una cuenta `.test` verificada, organización, concesión determinista de 1.000 créditos y reserva demo. Reset rechaza servicios externos, muestra sus objetivos, exige confirmación y recrea solo los datos de este proyecto Compose.

## Verificación

```bash
curl http://localhost:3000/api/health
curl http://localhost:3000/api/ready
pnpm test:fast
pnpm test:e2e
pnpm build
```

Playwright inicia sesión con Better Auth y prueba créditos tenant, subida Garage real y la tarea de imagen de cinco créditos hasta el worker y el resultado firmado.
