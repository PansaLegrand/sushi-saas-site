> Verificado con el commit [`8ecec8c`](https://github.com/PansaLegrand/sushi-saas-template/tree/8ecec8c3db8934598da5da044c507dc427808e61).

El repositorio entrega cuatro imágenes independientes: web, consola admin, worker durable y Content Studio opcional. PostgreSQL, Redis y objetos siguen siendo servicios externos con su propia disponibilidad, cifrado y copias.

| Proceso | Dockerfile | Puerto |
| --- | --- | ---: |
| Web | `Dockerfile.web` | 3000 |
| Admin | `Dockerfile.admin` | 3001 |
| Worker | `Dockerfile.worker` | ninguno |
| Content Studio | `Dockerfile.studio` | 3002 |

```bash
pnpm customize
./scripts/setup.sh production
pnpm containers:check
```

Los valores públicos `NEXT_PUBLIC_*` son argumentos de build; credenciales de base, auth, Stripe, Resend y storage son solo runtime. Las imágenes finales usan Node fijado y usuario no root, filesystem de solo lectura cuando aplica, capacidades eliminadas y ningún tooling de desarrollo.

Ninguna imagen migra al arrancar. Antes de promover:

```bash
pnpm db:migrate:prod
pnpm db:check:prod
pnpm launch:check
```

`launch:check` reúne configuración, entorno, contratos de contenedor, migraciones, integridad, retención, tests y builds. Usa skips solo si el mismo release registra el control equivalente.

**Listo para lanzar:** imágenes de una revisión, migraciones aplicadas, readiness sano, worker y scheduler activos, restore dentro del objetivo, sin flags demo, MFA admin verificado y auditoría verde.
