> スターターのコミット [`7d452a6`](https://github.com/PansaLegrand/sushi-saas-template/tree/7d452a6c327c8acaee98a8b00f9444003f5e63c8) と同期済みです。

Slack Incoming Webhook を作り `SLACK_WEBHOOK_URL` を設定します。SDK 構築は `src/integrations/slack.ts`、business code は route から Slack を呼ばず typed `slack_event` / `slack_error` job を enqueue します。

頻発 event は決定的 dedupe key を使い、request/order/job ID を含めますが、credential、token、生 request body、download URL、不要な個人情報は除きます。webhook 未設定は明示的な環境選択にします。

永続 runner が再試行します。`/api/cron/jobs` を認証・schedule し、失敗 job を監視し、重複、timeout/429/5xx、redaction、復旧をテストします。Slack は alert channel で、DB と structured log が system of record です。
