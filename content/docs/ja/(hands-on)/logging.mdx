> スターターのコミット [`7d452a6`](https://github.com/PansaLegrand/sushi-saas-template/tree/7d452a6c327c8acaee98a8b00f9444003f5e63c8) と同期済みです。

Node runtime は Pino、edge は同形 JSON を出力します。log は hosting が収集する stdout に送り、アプリは file を管理しません。`LOG_LEVEL` は `debug`、`info`、`warn`、`error` です。

request ID を route、service、job、Stripe order/event、provider call に伝播します。event、`org_uuid`、安全な UUID、job/order 番号、duration、result を構造化し、文章だけにしません。

authorization、cookie、password、token、API key は redact されます。生 request body、presigned URL、account export を記録しません。`respError` が内部 context を記録し翻訳済み `error_code` を返し、browser に `error.message` を出しません。

readiness、cron、retry 枯渇、webhook action-required、latency、5xx を監視し、Slack alert は ID で log に関連付けます。Slack は log store ではありません。
