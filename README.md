# Sushi SaaS website

The independent public website and documentation repository for
[Sushi SaaS](https://github.com/PansaLegrand/sushi-saas-template).

This repository is intentionally separate from the starter application. It
contains a multilingual landing page, implementation guides, engineering
articles, legal pages, and SEO routes. It contains no database, authentication,
Stripe, storage, job worker, or admin runtime.

## Local development

Requirements: Node 20.19 and pnpm 10.22.

```bash
cp .env.example .env
pnpm install
pnpm dev
```

The default site runs at `http://localhost:3000`.

## Content

| Directory | Public route | Purpose |
| --- | --- | --- |
| `content/docs/<locale>` | `/docs` | Versioned starter setup and implementation guides |
| `content/blog/<locale>` | `/blogs` | Editorial and architecture articles |
| `messages/<locale>.json` | — | Landing, navigation, legal, and index UI |

English uses unprefixed URLs. Other locales use `/zh`, `/es`, `/fr`, or `/ja`.
All five locales must carry the same content slugs.

Canonical URLs, alternate-language links, JSON-LD, the sitemap, and robots
metadata are generated by the application. Frontmatter canonicals are rejected
so translated content cannot silently point at an obsolete route.

## Quality gates

```bash
pnpm check
```

This validates content structure and links, lints, type-checks, runs rule tests,
and produces a production build. CI runs the same gates with a frozen lockfile.

## Relationship to the starter

The application source remains in
[`PansaLegrand/sushi-saas-template`](https://github.com/PansaLegrand/sushi-saas-template).
Co-versioned contributor and operational documents stay with that codebase;
public tutorials live here. A starter change that affects setup or behavior
should include a linked documentation change in this repository.
